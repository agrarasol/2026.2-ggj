# deathrat (GGJ 26/27)

Projeto desenvolvido para a **Global Game Jam 26/27**.

## 🎮 Jogue

- itch.io: https://itch.io/game/edit/5183088

## 🧾 Sobre

**deathrat** é um jogo feito em Unity durante a jam, com foco em escopo enxuto e entrega rápida.

## 🛠️ Tecnologias

- Unity (URP 2D)
- C#

## ▶️ Como executar o projeto

1. Abra este repositório no Unity Hub.
2. Use a versão de Unity compatível com o projeto.
3. Abra a cena principal em `Assets/Scenes/`.
4. Rode no Play Mode.

## 📁 Estrutura resumida

- `Assets/` — cenas, scripts, prefabs, sprites e áudio
- `Packages/` — dependências do projeto Unity
- `ProjectSettings/` — configurações do projeto
